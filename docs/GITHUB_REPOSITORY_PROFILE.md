Quellcode gesetzt werden können, damit sie bei zukünftigen Anpassungen und
Repository-Neuanlagen konsistent bleiben.

## Notes

- Die Kurzbeschreibung gehört in **Repository → About → Description**.
- Die Topics gehören in **Repository → About → Topics**.
- Für die öffentliche GitHub-Seite sollten README und Kurzbeschreibung dieselbe
  Produktpositionierung verwenden.
